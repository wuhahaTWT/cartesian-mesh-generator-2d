# 十万级网格展示素材

本目录仅用于后续展示。六张图片由已有最终求解网格重新绘制，绘图前核对了单元数与验证记录中的 SHA-256；未重新生成网格或重跑 CFD。

## GitHub Markdown 引用

仓库公开后，可直接使用下面的稳定路径引用本目录中的图片（示例）：

```md
![Fixed 32-segment circle](https://raw.githubusercontent.com/wuhahaTWT/cartesian-mesh-generator-2d/main/%E5%B1%95%E7%A4%BA%E7%B4%A0%E6%9D%90/01_circle_pure_153208.png)
```

六张图的文件名与下方标题一一对应。`main` 会随仓库更新；需要固定展示版本时，将 URL 中的 `main` 替换为具体 commit SHA。图片需已提交到公开仓库，访问者才能从 `raw.githubusercontent.com` 加载。

推荐讲述：已在三个固定几何上实现约 13–16 万个最终求解单元，支持纯 Cut-cell 与贴体边界层混合网格。

所有六例：内部 Solver、标准 OpenFOAM checkMesh 已通过；Q1 和扩展 checkMesh 仍失败。属于规模与工程能力验证，不代表工业级全面合格或网格无关性。圆输入为 32 段折线。
