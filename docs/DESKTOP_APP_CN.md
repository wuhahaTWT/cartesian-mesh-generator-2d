# 桌面使用

## 打开与版本

唯一前端在根目录 `desktop/src/`，沿用新版 0.2.0 的布局。
直接双击根目录 `打开CartMesh2D.command`；真正的 App 在 `desktop/dist/mac-arm64/CartMesh2D.app`。
开发模式：在 `desktop/` 执行 `npm start`。从其他目录调用 `sh desktop/scripts/build-macos.sh` 也可打包。
不要再打开旧隐藏工作区路径；新旧代码关系见开发导航的历史表。

## 使用顺序

1. 打开 .xy/.dxf/.svg/.csv/.txt，或选择内置样例。
2. 确认“轮廓内部是什么”：实体表示外部生成；流体域表示内部生成。喷管样例默认内部。贴体边界层支持外流和单环内流；带孔多环内流目前使用纯 Cut-cell。
3. 默认自动选参，选择常规或更密，再点“生成预览”。需要自己控制时切到手动设置，原来的参数和尺寸场预检仍在。无需输出目录。
4. 默认看物体周边；可切换物面近景或全域，滚轮缩放、拖动平移。观察范围不会改变实际计算域。配色/白底/暗底线框保留。
5. 满意后点击右上角“导出结果包”，保存一个 ZIP。解压后同一文件夹内包含网格、输入、参数与质量报告、OpenFOAM case；生成成功并不代表已自动运行外部 checkMesh。

预览使用系统临时目录，新一次生成替换上次可导出结果，正常退出 App 时清理临时缓存；需要保留的结果请先导出。生成与预检期间参数会锁定，可点击“取消当前操作”。左侧参数和右侧质量结果各自滚动。

失败时保留错误信息和输入参数，不要用随意降低质量阈值来生成一张看起来成功的图。

自动最多尝试 4 组，单次原生计算最多 180 秒；耗时提示是粗估，超过估计会明确说明。成功后显示实际参数，尝试记录放在 ZIP 内的 `selection.json`。如果更密参数失败后降密，会说明实际结果；不能保证所有模型自动成功。
内流选项只决定网格生成位置，不会自动替你完成喷管入口/出口及完整 CFD 边界条件配置。

喷管纯 Cut-cell 内流默认常规约 2,068 格，更密约 6,024 格；中心区也保留最低密度。选择内置喷管时手动模式同步加载常规配置。上述数量只对应当前内置型线。

贴体喷管自动常规 1,702 格，更密 3,106 格，均保留 3 层。自动模式根据内域选取余域小单元合并参数，最终参数随 ZIP 保存。

## 密度与速度怎么设置

纯路径以体长为单位描述尺寸场：远场倍数、壁面单元数、每级带宽、曲率、间隙、尾迹。
远场变大而壁面尺寸不变，会要求更深的树；全域最低层级变高，会让整个域变密，成本可能急剧增加。

壁面要求近似为 `ceil(log2((1 + 2 × 远场倍数) × 壁面单元数))`。
界面默认安全档 11 是测量边界，不是所有任意几何的成功保证。预检只解决尺寸场要求，不代替网格生成和质量检查。

手动区域坐标以体长为单位、相对物体中心，深度表示“低于壁面几级”。它与尺寸场叠加，域外部分不会产生网格。
不要只比较 level；同时看实际单元数、最小尺寸、生成时间及预览是否流畅。

hybrid 使用层数、绝对首层厚度、增长率、绝对外域留白等参数；没有纯路径尺寸场，默认上限 8。

## 输入与显示边界

- .xy 约定米；DXF 由 C++ 转换器处理单位和图层角色；无单位格式归一到最大跨度 1 m。
- SVG 目前不处理 transform/use 等完整 SVG 语义，存在隐藏定义被采作轮廓的缺陷；导入后必须核对形状。
- 坐标导入还存在负指数科学计数法和坏轮廓过滤问题；当前限制统一记录在 CURRENT_STATE，不把“支持格式”写成完全兼容。
- 两条路径均显示最终求解网格，按面积尺寸分档；尺寸档不是 Quadtree 树深。纯路径 `.solver.cm2d` 与 OpenFOAM 使用同一最终划分，原 `.cm2d` 保留生成过程网格。

## 质量怎么读

| 项目 | 含义 |
|---|---|
| 内部拓扑检查 | 生成器内部检查；未完整完成时显示未确认；不能代替独立验证 |
| Solver 质量 | 生成器导出的硬质量门 |
| Q1 | 更严格的分类型诊断；FAIL 不能被其他 PASS 覆盖 |
| BoundaryLayer OBSERVED | 有测量，尚未按完整边界层合同评级 |
| OpenFOAM 输出 | 表示写出了 case，不等于执行过 checkMesh 或求解 |

失败后若存在本次部分网格，可显示预览并明确失败，不能导出为完整结果包。每次运行使用独立目录，不读取旧产物。大输入与格式保形的已知边界仍见当前状态。

## 以后更换风格

当前配色与风格保留。界面颜色和字体变量集中在 `desktop/src/renderer/theme.css`；画布配色在 `viewport.js` 的 `THEMES` / `RAMP`。布局与滚动规则在 `style.css`。以后可以替换外观，不必重写生成与导出流程。

构建、真实桌面 smoke、独立读取器及 checkMesh 命令统一见 [开发导航](DEVELOPMENT_CN.md)。
