# 桌面使用

本页说明操作和参数；当前版本、验收结果与限制见[当前状态](CURRENT_STATE_CN.md)，源码构建和调试见[开发指南](DEVELOPMENT_CN.md)。纯笛卡尔浸入边界与流道拓扑优化目前只提供命令行工具。

## 打开与版本

从 [desktop-platforms](https://github.com/wuhahaTWT/cartesian-mesh-generator-2d/actions/workflows/desktop-platforms.yml) 下载全部成功且版本匹配的附件，解压外层附件及内部应用包，保留完整目录。

| 平台 | 启动与要求 |
| --- | --- |
| macOS | Apple Silicon 打开 `CartMesh2D.app`；本地已有构建可双击根目录 `打开CartMesh2D.command`，应用在 `desktop/dist/mac-arm64/`，Intel 本机构建在 `desktop/dist/mac/` |
| Windows | 打开 `CartMesh2D.exe`，保留同目录 resources；面向 Windows 10 1903+ / 11 x64，CI 实测系统是 Windows Server 2022，不代表所有桌面版本逐一验证 |
| Linux | 运行 `./cartmesh2d-desktop`；Ubuntu 22.04 x64 构建，需兼容 glibc 及 GTK/NSS/音频库的图形桌面，不是 Alpine/musl 通用包；正常启动不关闭沙箱 |

包自带 Electron、原生工具、样例与中文字体，运行不需要 Python、Node.js 或编译器；Windows 原生工具使用静态运行库和 UTF-8 路径配置。包未签名/公证，macOS 最低系统要求按实际构建记录解释。OpenFOAM/Fluent 需另行安装，网格生成不依赖它们。

已有源码和运行包时，也可用 `start-windows.cmd` 或 `start-linux.sh`；开发模式和缺包构建见开发指南。

## 使用顺序

1. 打开 XY/DXF/SVG/CSV/TXT、PNG/JPG，或选择内置样例。图片先按下文确认轮廓与尺寸。
2. 确认“轮廓内部是什么”：**实体**表示在外部生成流体网格，**流体域**表示在内部生成。喷管样例默认内部；贴体边界层支持外流及单环内流，带孔多环内流用 Cut-cell。
3. 选择方法与目标数量，确认计算域留白，点“生成预览”。默认自动选参，也可把建议或实际参数转入手动；预览无需输出目录。
4. 检查质量和实际数量。滚轮缩放、拖动平移，可选物面近景或全域；显示范围不改变计算域。
5. 点“导出结果包”保存 ZIP，先看 `mesh-preview.png` 与包内 `README_CN.md`。包保留输入、参数、质量报告及对应网格；写出 OpenFOAM case 不等于执行过 checkMesh。

预览保存在临时目录，新生成替换上次可导出结果，正常退出会清理临时缓存，重要结果须先导出。“回到开始”清空几何/画布但保留上一份可导出结果和参数。生成期间参数锁定，可取消；失败保留错误和输入，不能通过降低质量门制造成功。

按数量自动最多尝试 3 组，以目标 ±30% 为范围，保留最接近的成功结果；旧常规/更密入口最多 4 组。单次原生尝试预算 180 秒，耗时提示只是估计。实际尝试记录在 `selection.json`，不保证所有模型成功。

圆柱、翼型、喷管可“载入已验证高密样例参数”，会替换参考长度、留白和高深度选项并转入手动。内流选择只决定网格位置，不自动完成入口/出口等 CFD 边界配置。

## 纯笛卡尔背景网格

选择“纯笛卡尔背景网格”，再选全域均匀或四叉树局部加密，设置层级、留白与加密框。全部内外及相交方格保留，可看分类、尺寸与原始轮廓。

结果包包含分类 JSON、VTK、输入、参数和 PNG，**没有可求解的流体 CM2D/OpenFOAM**，也不开放流动、温度或可压求解。需要 CFD 时选择 Cut-cell 或贴体边界层。

## 在 App 里试算层流

生成有效流体网格后展开“原生层流”：

1. 选匹配几何的工况：外流、矩形通道、顶盖方腔、具有左右竖直端口的曲壁通道/喷管，或逐面命名边界。速度入口、压力出口、轴对齐静压开口、对称面、壁面均须核对真实位置。
2. 填速度与运动黏度 **ν（m²/s）**。速度分别表示外流入口、通道入口最大值或方腔顶盖速度；`Re=速度×参考长度/ν`，高 Re 湍流不能直接套用层流模型。
3. 选对流格式并启动。默认一阶迎风；两种限制重构可减少数值扩散，须在同网格比较，不能只看残差。完成后可看速度、运动学压力或网格。
4. 检查停止状态再导出。**达到迭代上限不算收敛**；`.flow.vtk` 供 ParaView 使用，`.flow.json` 保存工况和单位，`.flow.residuals.csv` 保存最后尝试步的内迭代。

外流模板为左入口、右出口、上下滑移及物面无滑移。计算域太紧可能干扰结果或引起出口回流。圆柱演示的速度 1 m/s、直径 2 m、ν=.1 m²/s 不是空气物性。压力显示 **p/ρ（m²/s²）**，乘密度才得到相应 Pa 压差；受力和流量均须按二维单位厚度理解。

| 数值选项 | 使用边界 |
| --- | --- |
| 线性精度 strict / adaptive | 独立层流可选 adaptive，最终仍严格复核 |
| 速度松弛 / 压力校正次数 | 默认 .6 / 4；困难网格可对照较小松弛与 1 次校正，增大参数不保证提速 |
| Anderson | 可选稳态加速；非定常和温度联算不使用 |
| 压力求解 | 默认 IC0，可试聚合多重网格；macOS 独立层流可选系统 Cholesky，可能更耗内存，失败可改回默认 |

温度联算仍用固定线性精度、.6 松弛和 4 次校正，不支持上述全部选项。改变线性方法不能跳过收敛门。

压力出口默认检测到回流就停止。试验性“允许法向回流”只适用于当前矩形域右出口，入口方向垂直出口、压力保持给定值；温度联算另需出口流入温度。结果记录真实回流面数/流量，续算锁定这个物理选项。

“保存/读取工况”只保存网格哈希绑定的物性、边界和控制，读取后仍要重新计算；它不保存完整几何项目或已接受流场。

### 非定常与续算

1. 时间模式选非定常，填写步长和本次步数；例如 .01 秒 × 20 步是 .2 秒，只是设置示例。
2. 从静止开始，逐步查看动能、受力与 CFL；每个时间步的内迭代通过后才推进时钟，完成本次时间段不等于达到稳态。
3. 完成或取消后可从保存状态继续；外部 `.checkpoint` 需要同一网格、物性、边界和格式，可调整步长及本次步数。

采用一阶后向欧拉；固定步长 CFL 是测量值，自动模式按目标 CFL、步长上下限和终止时间推进并重试失败候选。时间步控制不能代替时间精度与网格细化对照。

取消/失败保留上次完整显示，续算时钟可能更新，以各自标签为准。退出前导出 ZIP：完整结果用 `.flow.checkpoint`；取消后更新状态在 `flow-incomplete-*` 诊断目录及 `desktop-flow-error.json` 中。只用完整 checkpoint，不用 `.tmp` 或失败 CSV。`.flow.time-history.csv` 记录本次全部接受步。

## 在 App 里计算温度

1. 在原生层流中填工况、速度、黏度和时间设置；被动热输运始终按物理时间推进。
2. 填热扩散率、初温及热边界。外流设物面和入口条件；矩形内流按四边设置。
3. 启动温度与流动联算，检查温度、积分与守恒；可取消并联合续算。
4. 导出 ZIP，查看 `temperature-preview.png`。重开后生成同一网格，再载入 `.thermal.checkpoint`，保留旁边的 `desktop-state.json`，不要只载入 `.carrier.checkpoint`。
5. 载入联合状态会恢复热边界、取消旧的局部涡初值，保留可用的固定／自动时间模式。核对“联合续算状态”的时间，再填写本次步长和步数或绝对目标时间；步长可以改变，物性与边界继续锁定。LF 与 CRLF 换行的联合检查点均可读入，最终仍由原生求解器核对完整网格和配置。

| 输入 | 定义与单位 |
| --- | --- |
| 热扩散率 | `D=k/(ρcp)`，m²/s |
| 体积热源 | `Q/(ρcp)`，K/s |
| 向外热通量 | `q/(ρcp)`，K·m/s |
| 初温、定温 | K；300 K 约 27 ℃ |

自动步长共用上方目标时间、最大／最小步长、CFL 和重试预算，任一方失败回退整步。温度面板可开启“联合时间误差控制”：特征温升填需要分辨的温度变化（如 1 K），不要填 300 K 背景温度；启用后每次候选需要三个联合求解，仍为一阶。CFL／收敛控制与时间精度分别检查。桌面当前支持固定热边界；命名热边界和阶跃事件用 CLI，包含事件的 v2/v3 文件不能被当作静态桌面工况载入；无事件 v3 可完整保存／恢复建议步长。

默认值只作演示。这里温度不反馈流动，没有浮力、辐射或共轭传热。若出口回流，先核对域和工况；仅填写出口流入温度不会开启流动回流模式。`desktop-state.json` 标记 complete/failed/cancelled，失败目录 CSV 不代表已完成结果。

## 可压流动开发版

生成最终流体网格后展开“可压流动（试验）”：矩形内流可选 Sod 冲击管，物体外流使用机械/热壁与特征远场。这里压力是 **绝对压力 Pa**，与不可压入口不同。

| 选项 | 含义与边界 |
| --- | --- |
| 通量与阶数 | 默认 Rusanov 一阶；可选带激波保护的 HLLC/HLLE、受限线性/RK2 二阶。激波附近可能降阶，摘要记录回退与退阶次数 |
| 动力黏度 μ | Pa·s，默认 0；`μ=ρν`，不同于不可压 ν。正黏度可选静止无滑移；自由滑移不传递切向黏性牵引 |
| 导热系数 k | W/(m·K)，默认 0；直接改变气体总能量，温度反馈压力/密度/速度，不是被动热扩散率 |
| 热壁 | 绝热、指定温度 K、向外热流 W/m²；**负热流给流体加热**。外流只设物面，“封闭全部边界”还封闭外域 |
| 壁面梯度 | 默认线性，可选二次重构改善定温壁热流/无滑移应力，配合 HLLC/HLLE 二阶；邻域缺秩时报错，可细化或改回线性，整体仍是二阶 |
| 组合 CFL | 同时限制声学、导热、黏性过程，不超过 .45；小 Cut-cell 或大输运系数可能使显式步长很小 |

App 壁面均静止且使用统一热壁参数；CLI custom 边界可逐面设置热条件和切向壁速，不支持法向移动网格。开边界默认零 Fourier 通量，仍携带对流能量；黏性功与导热都计入总能量。

修改格式或物性会清除旧显示，计算时控件锁定。“到达目标时间”不等于稳态或物理精度合格。失败/取消保留最后接受检查点和上次完整结果；载入状态后物理条件锁定，通量、阶数和壁面梯度等数值格式可显式调整。

ZIP 记录实际格式、五种场图和续算文件；`faces.csv` 区分对流、黏性应力/功、导热与总通量，`history.csv` 保存接受步质量/能量及边界收支。向外净热量率是 W/m（二维单位厚度）。检查点版本与绑定细节见开发指南。

当前为恒物性理想气体层流，没有湍流、变物性、辐射、固体共轭传热或隐式推进。指定算例的误差改善和未完成精度问题见[当前状态](CURRENT_STATE_CN.md#可压层流开发版)。

## 用照片或图片生成网格

1. 打开 PNG/JPG/JPEG，在本地提取轮廓，无需上传或 API。
2. 核对红线；必要时切换深色/浅色/背景色、阈值及保留区域。
3. 闭合线稿可选“填充内部”，这会忽略内孔；默认保留孔洞。
4. 填写**红线整体最左端到最右端的实际宽度**及 mm/cm/m 单位，再确认轮廓。不是填写整张照片宽度。

优先用正视、清晰剪影和简单背景；透视、阴影或遮挡可能错认，不会恢复三维。取消识别保留之前几何。单图限 20 MB、4000 万像素，处理最长边缩至 1024 像素，默认约 1 像素简化；增加网格数不能恢复丢失细节。空白、截断或过复杂轮廓明确拒绝。

确认后换算为米并锁定源单位，ZIP 保存原图、`image-outline.png`、`image-import.json` 和网格预览。带孔/嵌套轮廓优先用 Cut-cell，贴体支持边界仍适用。

## 密度与速度怎么设置

| 想改什么 | 调整 |
| --- | --- |
| 整体数量 | 目标数量，或手动整体更细/更粗 |
| 物面 / 远处更细 | 减小壁面 / 背景尺寸 |
| 细格覆盖更远 | 增大加密带宽 |
| 计算范围更大 | 增大域留白；这会改变计算问题，不只改变数量 |

自定义数量为 1 千至 50 万，30 万以上仍须按规模试验理解；格数不等于精度。参考长度 Lref 可取包围盒最长边或工程长度，例如翼型弦长；壁面、背景尺寸及留白按 Lref 归一化。Lref=2 m、壁面 h/Lref=.005 对应 .01 m。

树深由计算域跨度与目标尺寸推导，四叉树取整可能使实现尺寸变化，须看最终报告。纯 Cut-cell 默认深度上限 11、贴体 8 是历史测量边界，可显式尝试越过但质量门不变；预检不等于生成通过。手动加密框坐标以 Lref 为单位、相对物体中心，深度表示低于壁面几级。

贴体还需首层高度/Lref、增长率、层数和挤出厚度/Lref。`.resolution.json` 分别报告切向/法向跨度与完整层数的壁长覆盖；面积平方根不能代表法向分辨率，默认层参数也不是按 y+ 反推的工程配置。

## 输入、质量与显示

- DXF 处理文件/显式单位；其他坐标按所选单位换算为米，“自动”按米提示，不做隐式归一化。SVG 尚不完整支持 transform/use 等语义，导入后必须核对形状。
- 画布显示最终求解网格，尺寸档不等于树深；纯路径 `.solver.cm2d` 与 OpenFOAM 使用同一最终划分，原 `.cm2d` 保留过程网格。
- 内部拓扑、Solver 质量、外部 checkMesh 分开判断；`BoundaryLayer OBSERVED` 仅表示有测量。Q1 已取消，历史 Q1 不作当前验收。
- 失败的部分网格可以明确标注后预览，不能导出为完整结果包；新运行不读取旧产物。

顶部可切换“现代简约 / 科研终端”，并记住选择；网格配色和背景另选，切换不会重生成网格。分栏按钮或 Cmd+B（其他平台 Ctrl+B）折叠侧栏；最小窗口 800×560，窄窗口工具栏换行。样式开发入口统一见开发指南。
