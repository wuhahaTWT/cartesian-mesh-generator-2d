# 桌面使用

## 打开与版本

唯一前端在根目录 `desktop/src/`，源码版本见 `desktop/package.json`，已打包版本与实际验收范围见 [CURRENT_STATE_CN.md](CURRENT_STATE_CN.md)。
macOS 直接双击根目录 `打开CartMesh2D.command`；Apple Silicon App 在 `desktop/dist/mac-arm64/CartMesh2D.app`，Intel 本机构建在 `desktop/dist/mac/CartMesh2D.app`。
开发模式：在 `desktop/` 执行 `npm start`。从其他目录调用 `sh desktop/scripts/build-macos.sh` 也可打包。
不要再打开旧隐藏工作区路径；历史从Git读取，见开发导航。

## Windows 与 Linux

GitHub 的 `desktop-platforms` 工作流在三个系统分别编译、打包并启动 App。只有原生测试、桌面测试和真实导入/生成/ZIP 读回全部通过，才上传对应运行包；在 Actions 中选择成功的一次运行，下载 `CartMesh2D-win-x64` 或 `CartMesh2D-linux-x64`。

- Windows：解压运行包，打开 `CartMesh2D.exe`，同目录的 resources 等文件必须一起保留。目标为 Windows 10 1903+ / Windows 11 x64；原生工具含 UTF-8 路径配置，不要求安装 Visual C++ 运行库。CI 实际系统是 Windows Server 2022，不代表所有桌面版本已逐一验证。
- Linux：解压 `.tar.gz` 后运行 `./cartmesh2d-desktop`。当前构建基线为 Ubuntu 22.04 x64，面向兼容 glibc 的图形桌面环境，并非 Alpine/musl 通用包。需要系统 GTK/NSS/音频库。正常启动不关闭 Chromium 沙箱。
- 运行包自带 Electron、二维生成器和中文界面字体；Python、Node.js、CMake、编译器只在开发构建时需要。OpenFOAM/Fluent 仍需另行安装或在目标计算环境中运行，网格生成不依赖它们。

当前包未签名/公证。详细的平台实测范围以 CURRENT_STATE 为准；尚未验收的平台不写成已支持。

已有源码时：Windows 双击 `start-windows.cmd`，Linux 执行 `./start-linux.sh`。缺少运行包时会提示构建命令，详见开发导航。

## 使用顺序

1. 打开 .xy/.dxf/.svg/.csv/.txt 或 PNG/JPG 图片，或选择内置样例。
2. 确认“轮廓内部是什么”：实体表示外部生成；流体域表示内部生成。喷管样例默认内部。贴体边界层支持外流和单环内流；带孔多环内流目前使用纯 Cut-cell。
3. 默认自动选参，选择目标数量（5 千、1.5 万、5 万、15 万、30 万或自定义），确认计算域留白，再点“生成预览”。需要自己控制时，可把建议或生成后的实际参数转入手动。无需输出目录。
4. 默认看物体周边；可切换物面近景或全域，滚轮缩放、拖动平移。观察范围不会改变实际计算域。配色/白底/暗底线框保留。
5. 满意后点击右上角“导出结果包”，保存一个 ZIP。解压后先打开 `mesh-preview.png`（白底全景＋壁面局部），再看 `README_CN.md` 的简短文件说明。包内仍保留网格、输入、参数与质量报告、OpenFOAM case；生成成功并不代表已自动运行外部 checkMesh。

标题栏的“回到开始”清空几何和网格画布，释放预览缓存；上一份结果仍可导出，生成新网格后替换。主题、显示模式和参数设置保留。生成或导出期间请等待结束，或先取消生成。

预览使用系统临时目录，新一次生成替换上次可导出结果，正常退出 App 时清理临时缓存；需要保留的结果请先导出。生成与预检期间参数会锁定，可点击“取消当前操作”。左侧参数和右侧质量结果各自滚动。

失败时保留错误信息和输入参数，不要用随意降低质量阈值来生成一张看起来成功的图。

按数量自动最多尝试 3 组，目标范围为 ±30%；保留最接近目标的成功结果，并说明是否达到范围。旧常规/更密入口最多 4 组。自动单次原生计算最多 180 秒；耗时提示是粗估。实际参数和尝试记录放在 ZIP 内的 `selection.json`，不能保证所有模型自动成功。
内流选项只决定网格生成位置，不会自动替你完成喷管入口/出口及完整 CFD 边界条件配置。

内置圆柱、翼型、喷管可点“载入已验证高密样例参数”：这会替换参考长度、域留白和高深度选项，转入手动；检查后再生成。喷管混合网格的通用数量初值仍可能失败，已有成功样例参数可从这里载入。

## 纯笛卡尔背景网格

网格方法选择“纯笛卡尔背景网格”，再选“全域均匀网格”或“四叉树局部加密”，设置层级、计算域留白及局部加密框。该模式完整保留轮廓内外单元，相交单元也不裁切；可切换几何分类与尺寸配色，叠加原始轮廓。

结果包保存分类JSON、VTK、输入、参数和预览PNG。背景网格没有可求解的流体边界条件，当前不会输出流体CM2D/OpenFOAM，也不开放流动、温度或Euler求解入口。需要实际CFD时选择Cut-cell或贴体边界层方法，并按流体位置配置内外域。

## 在 App 里试算层流

生成成功后，侧栏会出现“原生层流”：

1. 选工况：**外流**用于矩形外域内的物体；**通道**用于矩形内部流体；**顶盖方腔**用于方形内部流体。**曲壁通道／喷管**用于有明确左右竖直端口的内流；也可使用逐面命名边界配置速度入口、压力出口、轴对齐静压开口、对称面和壁面。请核对模板与真实边界是否一致。
2. 填速度和运动黏度 ν。外流是入口速度；通道是入口最大速度；方腔是顶盖速度。使用模型实际单位，`Re=速度×参考长度/ν`；此版只做不可压层流，不把高 Re 湍流硬套进去。
3. 选对流格式：默认“一阶迎风”便于先算通；“线性迎风（限制重构）”及“线性迎风（面方向限制）”可减少数值扩散，建议在同一网格上对照结果，不能只看残差选格式。点“启动层流求解”，可随时取消。完成后右上角可选**速度 / 运动学压力**，仍可切回网格。
4. 看状态后导出。**达到迭代上限不算收敛**；ZIP 中的 `.flow.vtk` 可用 ParaView 打开，`.flow.residuals.csv` 是收敛历史，`.flow.json` 记录工况和单位。

外流域左侧入口、右侧出口、上下滑移；物面无滑移。计算域过紧会干扰物理结果，也可能使出口出现回流而被拒绝。圆柱低 Re 试算可从速度1 m/s、直径2 m、ν=0.1 m²/s及较大域开始，不能把这套数值直接当成空气物性。压力图显示 p/ρ（m²/s²），不是 Pa；密度乘回去才是相应压力差。没有自动湍流模型或双向热流耦合，非定常涡脱落精度尚未验收。

“保存工况…”保存网格哈希绑定的物性、边界和数值/时间设置；“读取工况…”恢复设置后重新计算。它不保存完整几何项目或已接受流场，不能替代检查点。

独立层流可将“线性迭代精度”选为自适应，最终仍严格复核；速度松弛默认0.6，增大不保证稳定或更快。稳态可试Anderson历史迭代加速，非定常及温度联算不使用。“压力校正次数”默认4，困难网格可尝试1并降低速度松弛，原收敛门保持；是否更快或更稳定须逐例验证。温度联算保持固定线性精度、0.6松弛与4次压力校正。

### 非定常与续算

1. 时间模式选“非定常”，填**时间步长**和**本次步数**。例如 0.01 秒 × 20 步推进 0.2 秒；这只是时间设置示例，不是所有工况适用的推荐值。
2. 点“从静止开始计算”。下方曲线可选动能、受力或 CFL；每步内迭代通过才推进物理时间。“本次时间推进完成”不表示流动已经稳定。
3. 完成或取消后，勾选“从保存状态继续”再算。打开外部 `.checkpoint` 前先生成同一网格；物性、工况、网格和格式必须匹配，原生求解器会再次核对。可改时间步与本次步数。

取消或某步不收敛时，仍可查看上次完整结果；续算时间可能比显示场更新，以各自标签为准。退出 App 前先导出 ZIP：`.flow.checkpoint` 是完整结果的续算状态；取消后更新的状态保存在 `flow-incomplete-*` 诊断目录，配有 `desktop-flow-error.json`。只用完整 `.checkpoint`，不要用 `.tmp` 或失败候选 CSV 重启。

“压力求解”默认选**标准（IC0）**。大网格可试**多重网格（试验）**，macOS独立层流还可选**系统稀疏Cholesky**。这些方法可能加速部分网格，也可能多用内存，不保证每个案例更快；Cholesky在其它系统禁用，温度联算请选择IC0或多重网格。续算时可以切换；遇到聚合或分解失败可改回标准方法。结果和导出说明会记录实际使用的方法，不能靠切换方法跳过收敛检查。

曲线显示本次计算的已接受时间步，`.flow.time-history.csv` 保存本次全部步记录；`.flow.residuals.csv` 只记录最后尝试步的内迭代。采用一阶后向欧拉；固定步长模式的CFL是实测提示。自动步长模式按目标CFL、步长上下限和终止时间推进，未接受的候选步可缩步重试；自动控制不替代时间精度验证。细网格通常需要更小步长，可靠结果仍须比较不同时间步与网格。

三平台原生/前端回归与打包网格烟雾检查已建立；完整CFD桌面交互主要在macOS实测，不能用网格烟雾检查替代跨平台CFD交互验收。具体版本见当前状态。

## 在 App 里计算温度

1. 先生成网格，在“原生层流”填工况、速度、黏度、时间步和步数；热输运始终按物理时间推进。
2. 在“恒物性温度输运”填**热扩散率D**、**初温**。展开热边界：外流物面可设350K、入口流入300K；其余零通量表示没有扩散换热。矩形内流按左/右/上/下四边设置。
3. 点“启动温度与流动推进”。完成后看温度色图、温度积分与守恒监测；可取消，再勾选联合续算。
4. 退出前导出ZIP，先看 **temperature-preview.png**。重开App后生成同一网格，点“载入联合状态”，选 `.thermal.checkpoint`，保留旁边的 `desktop-state.json`；不要选 `.carrier.checkpoint`。

D=k/(ρcp)，单位m²/s；热源填Q/(ρcp)，单位K/s。指定通量是向外q/(ρcp)，单位K·m/s。初温和定值用K，300K约27℃。默认数值只是演示；物性须按实际材料填写。温度不反馈流动，无浮力、辐射和共轭传热。

**若报出口回流**：默认设置会停止，先检查出口位置、计算域与工况；需要时选择试验性法向回流，同时填写出口流入温度。单独填写温度不会开启流动回流模式。取消后的可续算时间可能比显示场更新，分别看标签。每次独立运行目录中的 `desktop-state.json` 标明 complete/failed/cancelled，失败目录的CSV不代表已完成结果。

## 用照片或图片生成网格

1. 点“打开文件”，选择 PNG、JPG 或 JPEG。程序在本地自动提取二维轮廓，无需上传或配置 API。
2. 看红线是否沿着所需边界。认错时切换“深色 / 浅色 / 背景色”或调整阈值；多个物体可点选其中一个，或选择保留全部区域。
3. 闭合线稿想取整个内部时，勾选“填充内部”；它会忽略内孔。默认不勾选，保留孔洞。
4. 填写**红线整体最左端到最右端的实际宽度**及单位（mm/cm/m），点“使用此轮廓”，然后照常设置数量、生成。填的是轮廓宽度，不是整张照片宽度。

优先使用正视图、清晰剪影、简单背景或透明底图片。复杂照片、阴影、透视和遮挡可能导致错认，程序不会从照片恢复三维形状。取消识别会保留之前的几何。

单图上限 20 MB、4000 万像素，识别时最长边缩至 1024 像素，轮廓默认约 1 像素简化；几何精度受原图和处理分辨率限制，增加网格数量不能恢复图片细节。空白图、边缘被截断或过度复杂的轮廓会明确拒绝。带孔/嵌套轮廓优先使用纯 Cut-cell，贴体路径的既有限制仍在。

标定后自动换算为米并锁定源单位。导出 ZIP 同时保留原图 `source-image.*`、确认红线图 `image-outline.png` 和标定记录 `image-import.json`，还包含生成网格的 `mesh-preview.png`。

## 密度与速度怎么设置

| 想改什么 | 调哪个参数 |
|---|---|
| 整体更多或更少格子 | 先换目标数量；手动可点整体更细/更粗 |
| 物体附近更细 | 减小壁面尺寸 |
| 远处更细 | 减小背景尺寸 |
| 细网格覆盖更远 | 增加加密带宽 |
| 更大的流体计算范围 | 增加域留白；这会改变计算问题，不能只为了凑数量 |

数量表示计算规模，不表示 CFD 精度。30 万为规模试验；自定义 1 千至 50 万。边界层初值不是按 y+ 推导，需结合实际工况设置。

两条路径共用 Lref。可选择包围盒最长边，或显式输入工程参考长度（米），例如翼型弦长。
填写壁面 `h/Lref`、背景 `h/Lref`、留白 `padding/Lref`，数值越小，要求越细。
例如 Lref=2 m、壁面 h/Lref=0.005，目标壁面尺寸为 0.01 m。
扩大计算域不会改变请求的物理壁面尺寸，但四叉树取整后的实现值可能改变，应查看预检与最终报告。

树深由 `ceil(log2(计算域跨度 / 目标壁面尺寸))` 推导。界面默认纯路径上限 11、贴体上限 8
是历史测量边界，不是任意几何成功保证；允许显式尝试越过，原质量门保持不变。
预检只解析尺寸，不代替网格生成和质量检查。不要以单元总数或树深判断 CFD 精度。

纯路径手动区域坐标以 Lref 为单位、相对物体中心，深度表示“低于壁面几级”。它与尺寸场叠加，域外部分不会产生网格。
不要只比较 level；同时看实际单元数、最小尺寸、生成时间及预览是否流畅。

贴体路径另填首层高度/Lref、增长率、层数和挤出厚度/Lref。生成后 `.resolution.json` 分别测量
壁面 owner 的切向和法向跨度，以及首层和完整请求层数的壁长覆盖率；面积平方根不能表示边界层法向分辨率。

## 输入与显示边界

- DXF 由 C++ 转换器处理文件单位与显式单位；图片使用确认的实际宽度标定；其他坐标格式按所选单位转换为米。“自动”对非 DXF 坐标文件按米读取并提示，不做隐式归一化。
- SVG 目前不处理 transform/use 等完整 SVG 语义，存在隐藏定义被采作轮廓的缺陷；导入后必须核对形状。
- 坐标负指数科学计数法与不完整环漏报已修复；SVG/CAD 当前限制统一记录在 CURRENT_STATE，不把“支持格式”写成完全兼容。
- 两条路径均显示最终求解网格，按面积尺寸分档；尺寸档不是 Quadtree 树深。纯路径 `.solver.cm2d` 与 OpenFOAM 使用同一最终划分，原 `.cm2d` 保留生成过程网格。

## 质量怎么读

| 项目 | 含义 |
|---|---|
| 内部拓扑检查 | 生成器内部检查；未完整完成时显示未确认；不能代替独立验证 |
| Solver 质量 | 生成器导出的硬质量门 |
| BoundaryLayer OBSERVED | 有测量，尚未按完整边界层合同评级 |
| OpenFOAM 输出 | 表示写出了 case，不等于执行过 checkMesh 或求解 |

当前产品取消 Q1 合同检测。内部拓扑、Solver 质量和外部 OpenFOAM `checkMesh` 仍需分别核对；Solver 门允许导出不代表外部 `checkMesh` 或指定工况已经通过，BoundaryLayer OBSERVED 也不是 PASS。旧版 Q1 结果属于历史证据，不作为当前产品状态。

失败后若存在本次部分网格，可显示预览并明确失败，不能导出为完整结果包。每次运行使用独立目录，不读取旧产物。大输入与格式保形的已知边界仍见当前状态。

## 切换风格

顶部可切换“现代简约”和“科研终端”，下次打开会记住选择。网格配色/白底/暗底线框仍单独选择；切换主题不会重新生成或改变网格。科研终端保留内置背景 artwork；首页显示背景，选择模型后网格画布使用独立纯色底。titlebar 的分栏按钮支持点击和 Cmd+B（其他平台 Ctrl+B）折叠侧栏，状态会持久化；窗口最小尺寸为 800×560，窄窗口下工具栏换行。

开发时颜色和字体变量集中在 `desktop/src/renderer/theme.css`；画布配色在 `viewport.js` 的 `THEMES` / `RAMP`，布局在 `style.css`。

构建、真实桌面 smoke、独立读取器及 checkMesh 命令统一见 [开发导航](DEVELOPMENT_CN.md)。

压力出口默认“检测到回流时停止”。需要处理出口流入时，可选“允许法向回流（试验）”：流入方向垂直右侧出口，压力保持给定值；仅适用于当前矩形计算域。结果显示真实回流面数及流入量。做温度计算还需提供出口的流入温度。续算会锁定这一物理选项；旧v1流动状态按停止模式读取，新v2显式保存模式。

## 可压流动开发版

在独立 `codex/compressible-flow` worktree 的 App 中，生成最终流体网格后展开“可压流动（试验）”。矩形内流可用 Sod 冲击管；物体外流使用所选机械/热壁条件和特征远场。这里的压力是绝对压力 Pa，与不可压的运动学压力不同。

通量可选原 Rusanov 或带激波保护的 HLLC；精度可选一阶或受限线性/RK2二阶。默认保留原方案。修改这两项会清除旧的显示结果，计算期间控件锁定；完成摘要和导出图会写明实际使用的格式。二阶改善光滑区分辨率，激波附近限制斜率；HLLC 正性回退次数与重构退阶次数均可查看。

“到达目标时间”只表示完成指定演化时间，不等于稳态或任意工况精度合格。失败/取消后保留最后接受检查点和上次完整结果；载入 `desktop-state.json` 时恢复所用格式，物理参数锁定，数值格式可显式调整。当前可选恒系数层流黏性与导热，未包含湍流、变物性或固体共轭传热。

动力黏度 `μ` 单位为 Pa·s，默认0关闭；它与不可压入口的运动黏度 ν（m²/s）不同，两者满足 μ=ρν。正黏度时可选“静止无滑移”，壁面同时限制法向和切向速度，形成黏性剪切；“自由滑移”不传递切向黏性牵引。黏性做功与导热共同进入气体总能量，不能把黏性视为仅平滑速度的开关。当前 App 壁面均静止；CLI 自定义边界可指定切向壁速，仍不支持法向移动的网格。

导热系数 `k` 单位为 W/(m·K)，默认0关闭；这是物理导热系数，不是被动温度入口的热扩散率。它直接改变气体总能量，温度通过状态方程反馈到压力、密度和速度。热壁可选绝热、指定绝对温度 K、指定向外热流 W/m²；**负热流表示给流体加热**。开边界默认零 Fourier 热通量，流出入仍会对流携带能量。外流工况只给实际物面设置热壁；“封闭全部边界”会将物面与外域边界全部设为固定壁（自由滑移或无滑移），适合检查封闭系统热量收支。

声学/导热/黏性组合 CFL 同时限制可压波传播、热扩散与动量扩散，取值仍不超过0.45。小 Cut-cell 或较大黏度/导热系数会使显式时间步很小；没有隐式推进加速。修改黏度或导热参数会清除旧显示，续算时这些物理参数锁定。结果包含导热系数、组合 CFL、向外净热量率 W/m（二维每单位厚度）；`faces.csv` 分开保存对流动量/能量、黏性应力/做功、导热与总通量，`history.csv` 保留所有接受步的总能量与边界热量。

μ>0 的检查点为 v3，绑定黏度、导热、机械/热壁及壁速；μ=0、k>0 为 v2，μ=k=0 保持 v1。不同物理条件不能混接，也不能把变更壁温后的运行称为相同物理条件的续算。CLI 的 `custom` 边界文件可给不同面设置不同热条件；当前 App 采用统一热壁参数。
