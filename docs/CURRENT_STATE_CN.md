## 密度、单位与最终测量

- 两条 CLI 与桌面使用共同尺寸场：显式参考长度 `Lref`、壁面 `h/Lref`、背景 `h/Lref`、留白/Lref；贴体首层和挤出厚度也可按 Lref 设置。树深度是派生诊断。自动参考取包围盒最长边，随旋转可能变化；需要旋转不变参考时显式设置 Lref。
- XY/CSV/TXT/SVG 按源单位换算为米，不隐式归一到 1 m。非 DXF 的“自动”按米读取并提示。SVG CSS/viewBox/transform 的全部物理语义尚未覆盖。
- `.resolution.json` 测量**最终求解拓扑**：实际单元数、面积等效尺寸分布、壁面边长、owner 切向/法向跨度，以及切向跨度超标的壁长占比和边 ID。请求尺寸不等于最终已实现尺寸，面积等效尺寸不能替代边界层方向尺寸。
- 层保留检查逐个核对源层 polygon、最终几何、唯一来源、wall owner 和连续 owner/neighbour。首层覆盖、完整请求层数覆盖、首层高度和超标比例分别报告。纯路径为 `not_requested`；fallback 为 `no_layers_retained`；缺失/改形/断连为 `incomplete`。
- 按壁面目标细分输入直线段，精确保留输入角点；细分不恢复原始折线没有表达的曲率。圆基准实际是固定 32 段多边形，不能当成精确圆的几何误差验收。法向尺寸不是经认证的 y+。
- 桌面实际能力表中，纯 Cut-cell 默认安全深度为 11、hybrid 为 8；此前笼统写为 8 不准确。高于对应默认深度仍需显式允许，质量阈值不变。本轮增加按数量的自动配置，范围和局限见下节。

2. **精度**：目标尺寸与最终尺寸有偏差；折线输入本身的几何误差、边界层方向尺度、流场误差和成本需共同控制。尚无自动 y+ 或误差驱动自适应闭环。
3. **鲁棒性范围**：九例有限扰动不代表任意几何。自交/零面积/非流形/分类冲突必须显式失败；旧重叠和伪造全零 AUDIT 反例仍在 `tests/repro/core-probe.cpp`，属于待修缺陷，不能据此放宽规则。
4. **输入与边界**：`tests/repro/hidden-spline-bulge.dxf` 漏检仍未消除；SVG transform 等处理不全。pure 可处理部分多环，局部孔洞可能显式拒绝；hybrid 当前限定单环，部分窄缝的 patch 身份/导出仍有缺口。
5. **桌面产品完整性**：保持最终求解网格预览和 ZIP；高档完整流程约 112 s，仍需定位预览/导出开销。数量自动配置已接入；分段边界条件 UI、物理精度预设、大 CAD 输入和跨机器安装还未全面验收。仅支持所列 OpenFOAM 路径，未验收所有 CFD 软件。
6. **工程纪律**：构建只用 `build/`，实验在忽略的 `outputs/`，不新增长期隐藏工作区/日期计划/代码副本。Q3/Q4 开关保留默认关闭及累积关系；不因局部失败无限追加阶段。确定性同工具链与跨编译器逐字节一致分别验收。

下一轮应集中修复有实际 CFD 影响的 Q1/几何缺陷、建立更明确的误差验收，并改善桌面端到端体验。新增问题归入这些既有目标，不能靠换参数、删坏格或隐藏告警“通过”。
