## 质量状态的口径

- Solver 硬门仍使用既有 policy（如 face weight 0.05、volume ratio 0.01、non-orthogonality 70°）。
- Q1 普通单元更严格；旧五个 H4 案例曾同时是 solver/checkMesh 通过、Q1 FAIL。那是历史指定参数的结果，不能冒充当前所有样例通过。
- BoundaryLayer 为 OBSERVED，不是完整合同 PASS。Q3/Q4/R1 修复有局部收益，未使所有案例达到 Q1。
- 外部检查没运行就写未运行；出现失败或仅写出部分文件不得记成整次成功。
- 历史 R1 的完成范围仅覆盖部分窄缝事务，sharp-tail 迁移未验收；Q2-B 是存档实验，不在当前主线。
