## 独立开发：纯笛卡尔网格 CFD

`codex/pure-cartesian-cfd` 从已验证 `main` 的 `ace13f9` 建立，原型基线为 `c0adb8f`。独立原生入口 `cartmesh2d_immersed_cli` 使用均匀 MAC 交错笛卡尔网格和不可压层流方程。全部方格及固体辅助未知量保留；原折线不平滑、不裁切。当前是 x 周期压差通道、y 两壁无滑移，支持通道/圆柱/静止多环 XY；未接入 App，不改变产品背景网格、Cut-cell 或共形边界层语义。

**当前进展是壁面处理**：可选 `--wall-method surface-penalty` 把真实壁面力与压力放进同一个校正方程。壁面按 MAC 插值区间做三点 Gauss 积分，力的分配是速度插值的加权转置；独立读取器检查壁面耗散、动量、全计算域连续性和整体受力。旧 Brinkman 模式保留为默认基线，新模式仍是有限惩罚实验版。相关方法和复现见 [开发入口](DEVELOPMENT_CN.md#纯笛卡尔浸入边界研究入口)。

以下均为 **128×32**、`nu=.01`、`drive=.12`、体积惩罚时间 `1e-4`，新壁面时间显式取 `1e-6`；每对使用相同原折线及停止量。百分比除以无障碍通道参考速度 `Uref=1`，不是除以各算例较低的实际平均速度。壁速为原折线上含角点、间隔不超过 `h/8` 的稠密采样最大值。

| 实际几何 | 旧方法最大壁速 / Uref | 新方法最大壁速 / Uref | 新方法最大法向速度 / Uref |
| --- | ---: | ---: | ---: |
| 圆柱（128 段原折线） | 9.1033% | **0.0783%** | 0.0319% |
| 斜壁四边形 | 15.5916% | **0.1355%** | 0.1335% |
| 与格线对齐的矩形 | 24.9262% | **0.0095%** | 0.0072% |
| 含凹角的 L 形 | 24.6079% | **0.0088%** | 0.0067% |
| 仅沿周期 x 平移 .37 格的圆柱 | 9.1166% | **0.1149%** | 0.0639% |

这些场均稳态收敛，独立方程和 VTK/CSV 读回通过；每个接受步仍检查原连续性门。壁面方程的代数残差与上述实际壁速分开记录，没有用标记点残差冒充无滑移精度。首次斜壁中点版本的标记最大壁速仅 .0138%，点间最大却达 1.6605%；原失败场保留，整段积分后的同案例为 .1355%。体积阻力单独增强 100 倍时圆柱最大壁速仍约 8.19%，没有用继续增强体积阻力掩盖壁面问题。

**整体物理精度仍未合格**：相同圆柱原折线从 128×32 加密到 192×48，平均流速 `.323263 → .349835`，相对粗网格变化 **8.22%**；法向最大壁速也未单调下降，因此不能称为网格无关。仅做 x 平移时新方法平均流量变化约 .0356%，是单个相位对照，不能外推所有位置/几何。近壁梯度、压力/表面应力、阻力和高 Re 边界层仍需针对性验证；不把小壁速或低代数残差当作这些量的精度证明。全域反力含辅助固体和体积/表面两部分，不等同于已验证表面应力积分。

系统 clang Release 构建与 **18 项直接相关检查**通过；包含原 11 项基础行为及耦合壁面、分段/方向不变性、孔洞、后端对照和损坏力导出检查。新矩阵使原 IC0 出现过非正主元，最小复现保留；现明确拒绝此组合，新模式 `auto` 使用 Jacobi，macOS 可选 Cholesky。旧模式的 IC0 默认不变。Jacobi 在本机完成小规模稳态，未宣称其他平台或大规模效率。

首阶段解析通道 L2 为 .1267%，同圆柱 IC0/Cholesky 加速记录保留于 [原型基线证据](../artifacts/current/native-cartesian-immersed.json)；它们不是新壁面模式的性能结论。此次未运行全量 CTest、前端、实际 App、平台 CI 或独立物理解对标。完整辅助计算格没有共形流体 polyMesh，外部 checkMesh 不适用，也不能用读取器代替现有 Cut-cell 质量门。下一步应检查近壁离散造成的流量/应力网格依赖；不自动改产品默认或合入 main。

## 已知限制与继续工作

当前顺序：**拓扑修复完整验收 → 圆环压力精度与默认稳定性 → 减少外迭代次数**。保持不可压层流范围，不再追加新流动形式。合入main表示软件集成通过，不表示这些物理问题已解决。

### 拓扑和网格

0.4.39修复近零轴坐标的端点身份：仅在原空间预算内复用近端点，双端都很近时仍保留参数判定；原输入坐标不移动。双单元回归覆盖三种尺度、两种遍历次序，保护极短线段。1024段/环完整生成消除了8条未分类边，7,233格诊断网格拓扑/面积通过，但原Solver质量仍有68项失败，因此拒绝最终导出及求解。[轴附近网格与证据](../artifacts/current/native-annulus-axis-fixed.json)

后续**研究修复**通过精确合并及一次内部顶点调整，形成7,071格：Solver失败68→0、方向连通失败95→0；独立读取确认面积2.3561797052753186、物面线段逐条不变。该修复尚未成为通用产品流程，不能把它写成发布版已支持所有细圆环。[研究网格](../artifacts/current/native-annulus-repaired-research.png)

复杂窄缝、尖角、多环、贴体层终止仍可能显式失败；原边界折线不得为改善外观而平滑。Q1已取消；Solver和方向连通门保留。标准checkMesh与扩展检查必须分开。

### 圆环压力精度

原256段细圆环压力L2约**2.776%**，高于原**0.5%**要求；扣除压力常数偏移仍约2.769%，不能靠换压力零点达标。[原圆环定位](../artifacts/current/native-annulus-error-localization.png)

独立生成1024段/环的7,071格研究网格：499轮、4.312秒、独立方程通过；速度L2 **0.05064%**，压力L2 **0.56442%（仍失败）**；转子/外壁力矩误差0.09518%/0.08509%，力矩不平衡0.01009%。tol1e-9加严至1e-11，最大u/v/p变化1.04e-7/1.03e-7/4.30e-8，压力误差基本不变。分段密度和网格同时变化，不能单独归因于拓扑修复；原256段输入未改。[完整证据](../artifacts/current/native-annulus-repaired-research.json)

### 默认稳定性与外迭代

默认strict、速度松弛.6、4次压力校正、无Anderson在困难圆环上仍失败。1次校正/.2/adaptive/Anderson可作为已测研究控制，不能当作通用最佳默认。

同一7,071格、4次校正/strict/.6/Anderson/tol1e-9，研究非正交校正状态阻尼0.5使**1,341→262轮，14.823→3.257秒**；两组独立方程通过，最大u/v/p差≤1.09e-9。研究算法未进入发布二进制，尚无十万格完整对照；接下来优先减少外迭代，不能只压缩单步耗时。

### 其他功能边界

- 图片识别不保证几何正确或网格可生成；SVG复杂transform/viewBox仍有未覆盖语义。
- 被动热输运无浮力或材料反馈；Euler/SST为保留实验入口，未取得通用工程精度资格。
- 原生与OpenFOAM受力、运动学压力、质量/体积流量的单位要分别核对；残差收敛不等于网格无关或物理准确。
