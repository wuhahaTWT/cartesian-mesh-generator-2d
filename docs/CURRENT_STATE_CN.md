## 独立可压开发线

当前 worktree 为 **`codex/compressible-flow`**，从 `main@ace13f9` 分出，独立构建、运行和输出。用户已授权在此推进可压流动；本轮未合入 main，也未改动并行拓扑优化工作区。下文0.4.40交付/平台记录属于既有 main 基线，不是此新算法的跨平台验收。

本轮在已有导热基础上补齐**恒物性可压层流的 Newtonian 黏性应力和总能量机械功**，采用 Stokes 假设。独立速度算子保留完整应力张量、交叉导数及非正交修正；每条真实面共享动量/功通量，热通量仍直接进入总能量。声学、热扩散和完整动量系数块的行范数共同限制每个 RK 阶段；失效缩步并保留接受状态，不修剪密度、压力或能量。

App 增加动力黏度μ（Pa·s）和静止无滑移壁，可继续设置绝热、定温或指定热流，并使用五种场图、取消/续算及ZIP。CLI自定义边界还支持切向移动壁，拒绝静止网格上的法向壁速。μ>0 使用绑定黏度、导热、机械/热壁和壁速的v3检查点；μ=0 保留原v1/v2。默认仍为μ=k=0、滑移壁、Rusanov一阶。

本轮黏性证据与范围：

- 系统clang完整构建无新增编译警告；**原生160/160、前端190/190通过**。完整原生串行回归301.16秒，原有门限未改；本轮没有磁盘门限阻断。macOS arm64运行时6个工具和13个样例检查通过。
- 32格扭曲网格及旋转网格上的平移、刚体转动、膨胀、剪切与一般仿射场：应力/功归一化误差最大 **1.41e-15**；直接扰动实际残差验证完整动量Jacobian行范数，相对差异 **3.78e-16**。静止绝热壁严格零质量/总能量通量，封闭能量相对误差 **1.76e-16**。
- 周期剪切波16/32/64格，按初始速度幅度归一化的L1误差 **2.185e-3 → 5.446e-4 → 1.361e-4**，最终观测阶 **2.001**。黏性/导热耦合小扰动用独立连续线性化矩阵指数参考，温度 **2.010**、密度 **2.257**、纵向速度 **3.077**；这不是一般流场的三阶精度声明。

- 正黏度四种对流/时间格式均经独立审计；中断/续算检查点逐字节相同，改黏度、壁面模型或壁速拒绝续算。零黏度与修改前二进制的Rusanov一阶/HLLC二阶、k=0/0.5共四组v1/v2检查点逐字节相同。新增通量、步长和历史的篡改测试均拒绝。
- 真实macOS App：**228格封闭腔体（μ=2）、3568格圆柱外流（μ=0.02）**，均无滑移、k=100 W/(m·K)、壁温400 K。每例六次运行覆盖重复确定性、物性更改清旧场、预算失败保留、取消/续算、物性锁定和ZIP；这些为短时测试物性，不是空气参数或稳态结果。12个接受状态的最后步黏性/热/对流通量与RK阶段独立核验通过，归一化差异最大 **3.90e-16**；全部相邻历史的质量/能量收支通过。两份ZIP各85个文件逐字节比对，OpenFOAM文件独立结构读取通过。
- 当前是**理想气体、常μ/k的可压层流开发版**。没有湍流、温变物性、辐射、固体共轭传热或隐式推进。修正热算子并非一般M矩阵；动量行范数和正性检查也不构成任意非正交网格的稳定/熵证明。开边界取零黏性牵引，小Cut-cell继续限制显式步长；任意几何壁面摩擦/热流精度、强激波与黏性相互作用及长期稳定性尚未验收。

## 已知限制与继续工作

既有main线顺序：**拓扑修复完整验收 → 圆环压力精度与默认稳定性 → 减少外迭代次数**。保持不可压层流范围，不再追加新流动形式。合入main表示软件集成通过，不表示这些物理问题已解决。

### 拓扑和网格

0.4.39修复近零轴坐标的端点身份：仅在原空间预算内复用近端点，双端都很近时仍保留参数判定；原输入坐标不移动。双单元回归覆盖三种尺度、两种遍历次序，保护极短线段。1024段/环完整生成消除了8条未分类边，7,233格诊断网格拓扑/面积通过，但原Solver质量仍有68项失败，因此拒绝最终导出及求解。[轴附近网格与证据](../artifacts/current/native-annulus-axis-fixed.json)

后续**研究修复**通过精确合并及一次内部顶点调整，形成7,071格：Solver失败68→0、方向连通失败95→0；独立读取确认面积2.3561797052753186、物面线段逐条不变。该修复尚未成为通用产品流程，不能把它写成发布版已支持所有细圆环。[研究网格](../artifacts/current/native-annulus-repaired-research.png)

复杂窄缝、尖角、多环、贴体层终止仍可能显式失败；原边界折线不得为改善外观而平滑。Q1已取消；Solver和方向连通门保留。标准checkMesh与扩展检查必须分开。

### 圆环压力精度

原256段细圆环压力L2约**2.776%**，高于原**0.5%**要求；扣除压力常数偏移仍约2.769%，不能靠换压力零点达标。[原圆环定位](../artifacts/current/native-annulus-error-localization.png)

独立生成1024段/环的7,071格研究网格：499轮、4.312秒、独立方程通过；速度L2 **0.05064%**，压力L2 **0.56442%（仍失败）**；转子/外壁力矩误差0.09518%/0.08509%，力矩不平衡0.01009%。tol1e-9加严至1e-11，最大u/v/p变化1.04e-7/1.03e-7/4.30e-8，压力误差基本不变。分段密度和网格同时变化，不能单独归因于拓扑修复；原256段输入未改。[完整证据](../artifacts/current/native-annulus-repaired-research.json)

### 默认稳定性与外迭代

默认strict、速度松弛.6、4次压力校正、无Anderson在困难圆环上仍失败。1次校正/.2/adaptive/Anderson可作为已测研究控制，不能当作通用最佳默认。

同一7,071格、4次校正/strict/.6/Anderson/tol1e-9，研究非正交校正状态阻尼0.5使**1,341→262轮，14.823→3.257秒**；两组独立方程通过，最大u/v/p差≤1.09e-9。研究算法未进入发布二进制，尚无十万格完整对照；接下来优先减少外迭代，不能只压缩单步耗时。

### 其他功能边界

- 图片识别不保证几何正确或网格可生成；SVG复杂transform/viewBox仍有未覆盖语义。
- 被动热输运无浮力或材料反馈；Euler/SST为保留实验入口，未取得通用工程精度资格。
- 原生与OpenFOAM受力、运动学压力、质量/体积流量的单位要分别核对；残差收敛不等于网格无关或物理准确。
