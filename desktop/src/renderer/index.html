几何信息

导入设置

支持 PNG/JPG 图片和 XY/DXF/SVG/CSV/TXT 轮廓。图片先确认轮廓与实际宽度；其他格式按源单位换算为米。

参考长度 Lref

可指定翼型弦长、圆柱直径或管道特征长度。指定值不会随模型旋转改变。

2生成设置

方法说明

替换参考长度、域留白和高深度选项，转入手动供你检查；不会立即生成。

留白决定外边界位置，按工况设置。改变数量档位不会改变留白；内流只划分轮廓内部。

加密分布与边界层

混合网格首层采用壁面尺寸的 1/4，属于几何初值，尚未按 y+ 配置。增加网格不代表精度已达标。

选择模型后显示建议参数。

目标范围为数量的 ±30%，最多调整 3 次尺寸与带宽；实际数量未达到会明确显示。

完整笛卡尔背景网格

完整保留模型内部单元，按几何标记外部、内部、相交；相交格不裁切。均匀模式每方向为 2 的层级次方格，最高9级。此模式导出JSON和VTK，未接入流体求解。

3网格疏密

数值越小，格子越细。0.01 表示参考长度的 1%。

例如 0.005 表示参考长度的 0.5%。实际尺寸由四叉树取整、边界裁切和质量修复共同决定，生成后提供实测报告。

3尺寸场

尾迹方向只控制网格加密，不改变流动入口方向或几何攻角。

手动加密区

坐标以 Lref 为单位、相对物体中心。这是尾流这类"非必要加密"区域的手动出口： 物面附近的加密由尺寸场保证，这里只管你想额外加密的地方。

3边界层与余域

贴体层与余域使用同一参考长度。急弯可能局部停层或回退；实际保留情况与质量结果分别报告。

4预览与保存

直接生成右侧预览，无需选择目录。临时结果仅供本次使用；需要保存时点击“导出结果包”，得到一个 ZIP。

小单元处理参数，并非密度或质量评分。通常保留样例值；提高它可能改变合并结果。

5原生层流

在最终网格上计算速度与压力。不含湍流模型；边界条件须与几何相符。

保存从零起算的流动设置，读取前须生成同一最终网格；续算请使用重启文件。温度设置单独配置。

一阶时间格式；从静止启动。减小时间步通常更准确，也更慢。

初始局部涡扰动

只在零时刻施加一次，支撑圆盘内平滑衰减到零；不改变入口或壁面。续算沿用已保存状态。

每个完成的时间步都会保存；取消后可继续。

边界绑定本次最终网格。重新生成网格后需要重新配置。

速度分量单位 m/s；出口运动学压力单位 m²/s²（Pa = ρ × 运动学压力）。不同面原有不同数值时，留空保持原分布，填写数值则统一该组。当前命名边界只计算流动，温度联算仍使用原预设。

圆环模板将参考速度作为初始内壁切向速度，外壁静止；生成后参考速度仍只用于归一化。沿曲壁平滑变化的速度选“平滑变化”移动壁面，折角处不连续的速度保留“逐面恒速”。圆环模板仅适用同心圆的规则多边形近似，方形环不适用。

线性迎风使用有界限制重构，可减少数值扩散，但不保证所有工况都更准确；这里不代表通用二阶格式或新的工程合格结论。

大网格可尝试多重网格或系统稀疏 Cholesky，内存可能增加，原收敛门不变。系统 Cholesky 仅用于 macOS 独立层流；温度联算请选择 IC0 或多重网格。

自适应精度可减少部分线性求解工作，最终收敛要求不变。松弛默认0.6；较大值可能更快，也可能不稳定。这两项用于独立层流的稳态或时间步内迭代，不改变物理时间步；温度联算保持默认设置。

默认4次非正交校正。困难网格可尝试1次并降低速度松弛；可能改善迭代稳定性，也可能减慢收敛。最终守恒和残差门不变，不代表物理精度已合格；温度联算使用4次。

可减少部分稳态算例的迭代；候选场需降低原动量残差并保持守恒，否则舍弃。收敛门不变，不保证所有工况更快。非定常和温度联算不使用。

压力出口保持给定压力；回流方向垂直出口，仅适用于当前矩形计算域。

可从默认 1e-6 加严到 1e-12，越严格通常越慢，过严可能触发迭代上限。控制动量残差和速度/压力变化；连续性门保持 1e-8。温度联算的流动容差取此值与 1e-8 中较严者；收敛不等于物理精度合格。

6恒物性温度输运

每步同步推进流动与温度，始终按物理时间计算。共用上方工况、黏度、速度、流动格式、压力求解、迭代上限和时间步设置。

单向恒物性模型：温度不反馈密度、黏度或浮力；不含共轭传热、辐射。
